# 1장 오픈월드 (버려진 묘지)

목표: **2km × 2km 의 음산하고 화려한 밤의 묘지 들판을 걸어 다닐 수 있는가.** 풀과 덩굴이 바람에 흔들리고, 늪에 달빛이 비치고,
하늘에는 보랏빛 성운과 오로라가 흐르고, 이름 있는 장소에 다가가면 "장소 발견"이 뜹니다.

월드 데이터는 월드 생성기(`Tools/WorldGen`)가, 소품 모델은 Blender 도구(`Tools/BlenderKit`)가 만듭니다.
Unity 에서는 **메뉴 세 번**이면 장면이 만들어집니다. 데이터 규격은 [Tools/WorldGen/SPEC.md](../Tools/WorldGen/SPEC.md) 입니다.

## 1. 만들기 (처음 10~20분, 대부분 기다리는 시간)

1. `git pull` 후 **Git Bash 에서 `git lfs pull`** (모델·텍스처·높이 데이터가 LFS 에 있습니다). Unity 를 엽니다.
2. Console 에 빨간 에러가 없는지 확인합니다. 셰이더 에러(`Shader error in 'Necro/...'`)가 있으면 멈추고 메시지를 보내 주세요.
3. 메뉴 **Tools → Necro → 월드** 에서 차례로:

| 순서 | 메뉴 | 하는 일 | 걸리는 시간 |
| --- | --- | --- | --- |
| 1 | **0. 소품 가져오기 설정 + 프리팹 만들기** | 소품 텍스처·모델 가져오기 설정, 재질, 소품마다 프리팹 | 1~3분 |
| 2 | **1. 1장 오픈월드 만들기** | 지형 4타일·풀·나무·소품·광원·물·효과·주인공을 넣은 장면 `World_Ch1` | 2~10분 |
| 3 | **2. URP 설정 맞추기** | Forward+, 그림자 150m·4단, 깊이 텍스처, HDR (프로젝트에 한 번만) | 몇 초 |

- 0번 메뉴를 건너뛰고 1번 메뉴를 누르면 "프리팹이 없어요" 창이 뜹니다. **0번 실행 후 계속** 을 누르면 알아서 이어 합니다.
- 1번 메뉴는 이미 장면이 있으면 **기존 장면 열기 / 새로 만들기** 를 묻습니다. 새로 만들면 장면에서 손으로 고친 배치는 사라집니다.
  지형 데이터·재질 파일은 같은 파일을 고쳐 쓰므로 여러 번 눌러도 깨지지 않습니다.
- 2번 메뉴(URP)는 순서와 상관없지만, 하지 않으면 늪의 물가가 옅어지지 않고(깊은 물로만 보임) 등불이 많은 곳에서 빛이 빠질 수 있습니다.
- 데이터 파일이 없거나 형식이 틀리면 무엇이 없는지 알려 주는 창이 뜨고 멈춥니다. 그 내용을 그대로 보내 주세요.
- 끝나면 Console 에 요약이 나옵니다 (지형·풀·나무·소품·광원 수, 걸린 시간, 경고). **경고가 있으면 그 내용을 보내 주세요.**

4. `Assets/_Necro/Scenes/World_Ch1` 이 열린 상태에서 **Play**.

### 만들어지는 파일

| 위치 | 내용 |
| --- | --- |
| `Assets/_Necro/Prefabs/Environment/<이름>.prefab` | 소품 프리팹. 모델(FBX)을 바탕으로 한 프리팹 변형 + 재질 + 충돌 + LOD 전환 + 그림자 + 광원 |
| `Assets/_Necro/Art/Materials/Props/` | 소품 재질 (`<이름>`, `Glow_Soul` 등 발광 4종, `Foliage`) |
| `Assets/_Necro/Art/Materials/World/` | 물, 효과 입자, 월드용 하늘 (`NecroSky_World`) |
| `Assets/_Necro/Art/World/Ch1/Generated/` | 지형 데이터 4개, 지형 층, 지형 재질, 물 격자, 조명 설정 — **데이터에서 다시 만들 수 있는 파일** |

> `Generated/` 의 지형 데이터는 타일 하나에 수십 MB 입니다. 도구로 언제든 다시 만들 수 있으므로 Git 에 올리지 않는 쪽을 권합니다
> (`.gitignore` 에 `/Assets/_Necro/Art/World/Ch1/Generated/` 추가). 정하시면 그대로 맞추겠습니다.

### 소품 프리팹 규칙 (manifest.json 의 META)

| META | 프리팹에서 |
| --- | --- |
| `kind: prop / scatter / landmark` | 일반 프리팹. 정적 플래그는 가림 컬링용만 (정적 배칭은 메모리가 커져서 쓰지 않음) |
| `kind: tree` | 지형 나무 프로토타입. 충돌은 뿌리의 캡슐 (지형 나무 충돌이 확실히 지원하는 형태) |
| `kind: detail` | 지형 풀. 뿌리에 LOD0 메쉬 하나 (지형이 인스턴싱으로 그림), 충돌 없음 |
| `collider: mesh / box / capsule / none` | 메쉬는 LOD1 메쉬로 (가볍게), 상자·캡슐은 모델 크기에 맞춤 |
| `cull` | LOD 마지막 단계가 사라지는 화면 높이. 중간 전환은 크기에 맞춰 거리로 정함 (작은 것 15m~, 큰 것 90m~). 값이 커도 30m 안(광원이 든 초·버섯은 50m 안)에서는 사라지지 않음 |
| `shadows` | 그림자 드리우기 켜기/끄기 |
| `light` | 발광 부품 자리에 일렁이는 점광원 (`SoulFlicker`) |

재질 슬롯 이름으로 재질을 고릅니다: `Main`(굽기 텍스처) / `Glow_Soul`·`Glow_Spirit`·`Glow_Toxic`·`Glow_Ember`(발광, HDR) / `Foliage`(잎 아틀라스).
`manifest.json` 이 없으면 META 없이 기본값(일반 소품, 메쉬 충돌)으로 만듭니다. 텍스처는 새 버전 `_albedo.jpg` 를 먼저, 없으면 이전 버전 `_albedo.png` 를 씁니다.
소품 폴더에 새 파일이 들어오면 가져오기 설정은 자동으로 맞춰지지만, **프리팹은 0번 메뉴를 다시 눌러야** 새로 만들어집니다.

## 3. 셰이더

| 셰이더 | 하는 일 | 조정 |
| --- | --- | --- |
| `Necro/Foliage` | 풀·덩굴·이끼. 바람에 흔들림(정점 알파만큼), 주인공 주변 풀이 밀려남, 빛을 등진 잎이 비침(반투과), 그늘은 보랏빛, 멀리서는 풀밭이 부드럽게(위쪽 법선) | `Materials/Props/Foliage` |
| `Necro/Water` | 어둡게 반사하는 늪 물. 잔물결, 하늘 반사(지평선 = 안개 색), 달길과 반짝임, 등불 반사, 물가가 옅어짐 | `Materials/World/Water` |
| `Necro/Sky` | 밤하늘 + **새로**: 흐르는 얇은 구름 띠, 보랏빛 성운 띠, 오로라 커튼, 달 표면 무늬, 별똥별 | `Materials/World/NecroSky_World` (룩 장면은 `Materials/Look/NecroSky`) |

바람 세기·방향·돌풍, 풀이 밀려나는 반지름은 `World Systems` 의 **Necro Wind** 에서 바꿉니다.

광원 컬링(`World Systems` 의 **Light Culler**): 광원마다 끄는 거리가 다릅니다 (빛 범위 × 12, 30~200m). 끄는 거리에 가까워지면 세기가 서서히 줄어 꺼지고,
다가가면 서서히 켜집니다. 동시에 켜 두는 광원은 48개까지입니다. 처음부터 꺼 둔 광원은 건드리지 않습니다.

## 알려진 한계

- **이 도구와 셰이더는 Unity 를 실행할 수 없는 환경에서 작성했습니다.** C# 은 Unity API 스텁으로 컴파일만 확인했고, 셰이더는 URP 6000.0 소스와 대조만 했습니다.
  첫 실행에서 에러나 어색한 부분이 나올 수 있고, Console 메시지와 스크린샷을 받아 고칩니다.
- 하늘과 물의 모양은 같은 식을 Python 으로 옮겨 그려 보고 다듬었지만, Unity 화면과 똑같다는 보장은 없습니다 (톤매핑·블룸에 따라 다름).
- 지형 나무의 회전 방향(`TreeInstance.rotation`)은 Unity Y 회전과 같다고 가정했습니다. 비대칭 바위·나무가 데이터와 반대로 돌아 보이면 알려 주세요.
- 지형 나무(kind = tree)의 충돌은 캡슐입니다. 바위를 지형 나무로 쓰면 충돌이 둥글게 잡히고, 캡슐 중심이 모델 원점이라
  원점이 몸체 가운데가 아닌 바위(`rock_a`)는 충돌이 몸체에서 0.3m 쯤 어긋납니다.
- 장소 발견 기록은 아직 저장하지 않습니다 (Play 를 다시 누르면 처음부터). 발견 알림과 지도는 IMGUI 로 그린 **임시 UI** 입니다.
- 지도 그림(`Assets/_Necro/Art/World/Ch1/map.png`)이 없으면 M 지도에 "지도 그림(map.png)이 없습니다" 가 뜹니다 (장소·주인공 표시는 그대로). 뜨면 알려 주세요.
- 풀의 "인스턴스 수 모드"와 비탈에서 풀이 기우는 설정(META `align`, 갈대는 곧게)은 Unity 2022.2 이상 기능입니다 (Unity 6 에서는 켜짐).
- 지형 풀은 70m 밖에서 그리지 않습니다. 안개가 옅어 풀밭이 끝나는 선이 보일 수 있습니다.
  `Necro/Foliage` 에 끝에서 풀을 오그라뜨려 감추는 값(`_FadeStart`·`_FadeEnd`)이 있지만, 덩굴·이끼와 재질(`Foliage`)을 같이 쓰므로 아직 꺼 두었습니다.
- 풀 한 포기 모델이 무겁습니다 (410~650 삼각형, 지형 풀은 LOD 가 없음). 넓은 풀밭에서 프레임이 낮으면 지형 4장의 Settings → Detail Density 를 낮춰 보고 차이를 알려 주세요.
- 개울 웅덩이 물 판 4장이 같은 높이에서 서로 조금 겹칩니다. 겹친 곳에서 물빛이 얼룩지거나 깜박일 수 있습니다.
- 물 재질(`Materials/World/Water`)은 처음 만들 때만 셰이더 기본값(물가가 옅어지는 깊이 0.6m, 물거품 폭 0.18m)을 받습니다. 1번 메뉴를 다시 눌러도 이미 있는 물 재질의 값은 바뀌지 않습니다.
- 굽는 조명(라이트맵)·가림 컬링 굽기는 쓰지 않습니다. 실시간 달빛 + 주변광입니다.
- 물은 굴절이 없습니다 (어두운 늪이라 거의 보이지 않음). 물 셰이더는 GPU Resident Drawer(DOTS 인스턴싱)를 지원하지 않습니다.
- 지형 데이터 파일이 커서 Git 관리 방법을 정해야 합니다 (위 `Generated/` 참고).
