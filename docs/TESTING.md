# 테스트 체크리스트

PC를 켰을 때 위에서부터 순서대로 해 보시면 됩니다. 전부 약 1시간 분량입니다.
**아직 아무것도 실제 화면에서 확인된 적이 없습니다.** 안 되는 항목이 나오는 것이 정상이고, 그걸 찾는 것이 이 테스트의 목적입니다.

결과는 항목 번호와 함께 편하게 적어 주세요. 예: "A3 안 됨 — 묘지기가 안 죽음", "B2 보라색이 너무 진함".

## 0. 준비 (5분)

```bash
git fetch origin
git checkout ccr-dd55526f-fxg7r3
git pull
```

- [ ] **0-1** Unity를 열었을 때 Console에 빨간 에러가 없다
  - 있으면 **다른 테스트는 멈추고** 에러 메시지를 전부 복사해 보내 주세요. 에러가 하나라도 있으면 Play가 안 됩니다
- [ ] **0-2** Console에 셰이더 에러(Shader error in 'Necro/...')가 없다

## A. 프로토타입 — 기본 흐름 (20분)

`SampleScene`에서 Play. 조작표는 [PROTOTYPE.md](PROTOTYPE.md).

- [ ] **A1** 시작 화면이 뜨고, 클릭하면 시작하면서 화면 아래에 대사 자막이 나온다
- [ ] **A2** 해골 병사를 쓰러뜨리고 E로 지배하면 군단에 들어온다. 첫 지배 때 주인공 대사가 나온다
- [ ] **A3** 군단 3마리 → 북쪽 납골당에 가까이 가면 묘지기와의 대사 → 묘지기 처치
- [ ] **A4** 묘지기 처치 직후 "상급 마법 해금" 안내가 뜨고, 기술 막대의 이름이 바뀐다 (영혼 탄막, 뼈 창 비…)
- [ ] **A5** 묘지기 시체 앞에서 E를 길게 → 주인공이 **무릎을 굽히고 손을 내미는** 동작 → 대사 → 묘지기가 이름을 받고 군단에 들어온다
- [ ] **A6** 납골당 근처에 더 이상 적이 다시 나오지 않는다 (정복의 흔적)
- [ ] **A7** 북동쪽 고룡 처치 → "금주 해금" → 고룡 시체를 E 길게 → 본드래곤
- [ ] **A8** V로 탑승, 남서쪽 하늘의 부유 성채로 비행
- [ ] **A9** 부유 성채에 도착하면 **망자의 군주**와의 대사가 나온다
- [ ] **A10** 망자의 군주 전투: 세 가지 패턴이 번갈아 나온다
  - 대검 내려찍기 (붉은 원이 퍼진 뒤 범위 피해)
  - 어둠의 창 (바닥에 작은 원 여러 개 → 1초 뒤 기둥이 솟음)
  - 해골 4마리 소환
- [ ] **A11** 성채의 적을 모두 쓰러뜨리면 클리어 대사 + "왕관 스킬 해금"
- [ ] **A12** 망자의 군주 시체를 E 길게 → 대사 → 군단에 들어온다 (슬롯 6칸)

**느낌 질문** (가장 중요):
- 지배할 때 손맛이 있나요? 번거롭지는 않나요?
- 군단이 싸우는 걸 구경만 하게 되나요, 내가 할 일이 충분한가요?
- 묘지기 / 고룡 / 망자의 군주 난이도는? (너무 쉬움 · 적당 · 군단이 녹음)

## B. 스킬 단계와 왕관 스킬 (10분)

진행하지 않고 바로 보려면 **F1** (기술 단계 전환 + 왕관 스킬 열기).

- [ ] **B1** F1을 누를 때마다 하급 → 상급 → 금주로 바뀌고 기술 막대의 이름이 바뀐다
- [ ] **B2** 상급: 영혼 탄막(여러 적에게 다발) · 뼈 창 비(우클릭, 하늘에서 쏟아짐) · 연쇄 폭발(Q) · 광란(R) · 대량 지배(E, 범위 넓음)
- [ ] **B3** 금주: 영혼 폭풍(좌클릭 누르고 있기) · 거신의 척추(우클릭, 일직선 기둥) · 망자의 해일(Q, 시체가 날아가 폭발) · 불사의 군단(R) · 왕관의 부름(E)
- [ ] **B4** 불사의 군단을 쓰면 8초 동안 군단이 정말 안 죽는다
- [ ] **B5** **Z** 강림: 본드래곤이 머리 위를 지나가며 일직선 폭격 (본드래곤에서 내려 있을 때)
- [ ] **B6** **G** 왕관 스킬 사용, **T**로 종류 바꾸기 — 5종이 모두 동작한다
  - 망자의 군세: 해골 28마리가 30초 동안 솟아나 싸움
  - 칠야의 유성: 화면이 어두워지고 넓은 범위에 창이 쏟아짐
  - 죽음의 영역: 초록 원 안에서 적이 죽으면 **자동으로 군단이 됨**
  - 피의 해일: 붉은 파도가 앞으로 쓸고 지나가며 군단 체력 회복
  - 역병의 안개: 감염된 적끼리 옮고, 죽으면 폭발

**느낌 질문**:
- 하급 → 상급 → 금주로 갈 때 "확 강해졌다"가 느껴지나요?
- 화면 흔들림, 번쩍임, 느려지는 시간이 과한가요, 부족한가요?
- 왕관 스킬 5종 중 가장 마음에 드는 것과 가장 심심한 것은?
- 금주가 너무 강해서 싸움이 시시해지나요?

## C. 군단과의 유대 (10분)

- [ ] **C1** 망령 기사(동쪽 폐허)를 E 길게 지배하면 이름을 받고, 가까이 가면 머리 위에 이름이 보인다
- [ ] **C2** **Tab** 군단 명부가 열리고 이름 · 등급 · 레벨 · 전적이 보인다
- [ ] **C3** 명부의 "이름 쓰기"로 **한글 이름**을 입력할 수 있다 (안 되면 알려 주세요. "다른 이름" 버튼은 무작위 이름)
- [ ] **C4** 해골 병사가 적을 몇 번 처치하면 "진화! 해골 기사"가 뜨고 몸집이 커진다
- [ ] **C5** 오래 살아남은 소환수가 "★ 고참"이 되고 주인공이 한마디 한다
- [ ] **C6** 이름 붙은 소환수가 쓰러지면 주인공이 한마디 하고, 시작 지점 제단 옆에 묘비가 선다
- [ ] **C7** 묘비에 가까이 가면 이름과 전적이 보인다. Tab 명부 아래 "추모"에도 나온다

**느낌 질문**:
- 이름 붙은 소환수를 잃었을 때 아까운가요? 아무 느낌이 없나요?
- 대사 자막이 읽을 만한 속도인가요? 전투를 가리나요?
- 주인공 말투("내 뒤로 오렴", "이제 쉬어도 돼")가 머릿속 인물과 맞나요?

## D. 군단 명령 (5분)

- [ ] **D1** F: 돌격 → 호위 → 후퇴가 바뀌고 군단 행동이 달라진다
- [ ] **D2** **마우스 휠 클릭**: 겨눈 지점에 파란 표시가 뜨고 군단이 그 자리로 가서 지킨다
- [ ] **D3** 그 상태에서 내가 멀리 가도 군단은 그 자리에 남는다. F를 누르면 다시 따라온다

**느낌 질문**: 지점으로 보내는 명령이 쓸모가 있나요? 더 세밀한 명령(부대 나누기 등)이 필요하다고 느껴지나요, 지금도 충분한가요?
→ 이 답이 기획서의 "군단 조작의 깊이" 결정에 쓰입니다.

## E. 룩 — 프로토타입에서 미리보기 (5분)

- [ ] **E1** 프로토타입 플레이 중 **F2** → 캐릭터에 외곽선과 또렷한 음영이 생기고, 밤하늘(별·달)이 보인다
- [ ] **E2** 다시 F2 → 원래대로 돌아온다
- [ ] **E3** 분홍색으로 보이는 물체가 없다

스크린샷: F2 켠 상태로 군단과 함께 싸우는 장면 한 장.
(도형 캐릭터라 상자 모양 부품은 외곽선이 모서리에서 끊어져 보입니다. 실제 모델에서는 나아집니다.)

## F. 룩 — 묘지 테스트 장면 (10분)

자세한 설명은 [LOOK.md](LOOK.md).

- [ ] **F1** Tools → Necro → 룩 → **묘지 룩 테스트 장면 만들기** 가 에러 없이 끝나고 장면이 열린다
- [ ] **F2** Play → WASD로 임시 주인공이 걸어 다니고 마우스로 카메라가 돈다
- [ ] **F3** 밤하늘, 달, 보랏빛 안개, 일렁이는 등불, 떠다니는 영혼 불티, 땅안개가 보인다
- [ ] **F4** 제단 앞 인형 셋: 외곽선이 있고, 가운데 인형(지배된 망자)만 보랏빛으로 일렁인다
- [ ] **F5** **F3** 키로 분위기 4종이 바뀐다: 차가운 달빛 / 핏빛 황혼 / 영혼 안개 / 잿빛 새벽

스크린샷 (분위기마다 한 장씩이면 가장 좋습니다):
1. 시작 지점에서 제단 쪽 전체
2. 인형 셋을 가까이서

**느낌 질문**:
- 네 분위기 중 어느 것이 머릿속 그림에 가장 가깝나요? (섞고 싶으면 "1번인데 안개는 3번처럼" 식으로)
- 너무 어둡나요, 밝나요? 보라색이 과한가요?
- 외곽선이 굵은가요, 가는가요?
- "이 게임/애니의 이 장면 같았으면" 하는 예시가 있나요?

## 문제가 생기면

| 증상 | 보내 주실 것 |
| --- | --- |
| Console에 빨간 에러 | 메시지 전체 복사 (첫 번째 에러가 가장 중요) |
| 분홍색 물체 | Console의 Shader error 메시지 + 스크린샷 |
| 게임이 멈춤/튕김 | 직전에 누른 키와 상황 |
| 메뉴에 Tools → Necro가 없음 | Console 에러 (컴파일 에러가 있으면 메뉴가 안 생깁니다) |
| 숫자가 이상함 (너무 강함/약함) | 어떤 기술·적인지와 느낌 |
