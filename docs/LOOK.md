# 룩 확정 단계

목표: **묘지 한 장면을 30초 봤을 때 "이 분위기다" 싶은가.** 통과하면 이 장면에 든 시간과 비용을 기준으로 1장 전체를 계획합니다.

방향은 **애니풍 다크 판타지**입니다. 밤, 차가운 달빛, 보랏빛 그늘, 영혼 불꽃의 번지는 빛, 또렷한 외곽선.

## 1. 테스트 장면 만들기 (5분)

1. `git pull` 후 Unity를 엽니다. Console에 빨간 에러가 없는지 먼저 확인하세요.
2. 메뉴 **Tools → Necro → 룩 → 묘지 룩 테스트 장면 만들기**
3. `Assets/_Necro/Scenes/Look_Graveyard` 장면이 만들어지고 열립니다. **Play**를 누르고 WASD·마우스로 걸어 다녀 보세요.

장면에 있는 것:

| 요소 | 내용 | 조정하는 곳 |
| --- | --- | --- |
| 밤하늘 | 별, 달, 달무리, 보랏빛 지평선 | `Art/Materials/Look/NecroSky` |
| 달빛·주변광·안개 | 차가운 달빛, 보랏빛 그늘, 먼 곳이 하늘에 녹아드는 안개 | `Moon Light` 오브젝트, Window → Rendering → Lighting → Environment |
| 후처리 | 번지는 빛(블룸), 색 보정, 그늘 보라 물들임, 화면 가장자리 어둡게 | `Settings/DarkFantasyProfile` |
| 영혼 등불 | 일렁이는 보랏빛 광원 7개와 제단의 영혼석 | 각 `Lantern` 아래 `Light` |
| 영혼 불티·땅안개 | 떠다니는 입자 | `Soul Wisps`, `Ground Mist` |
| 툰 셰이더 인형 3개 | 제단 앞. 왼쪽부터 **적(바랜 뼈) / 지배된 망자(영혼 효과) / 금속 갑옷** | `Art/Materials/Look/Dummy_*` |
| 임시 주인공 | 걸어 다니는 인형. VRoid 모델로 교체 예정 | — |

**분위기 프리셋 4종**: 플레이 중 **F3**을 누르면 차가운 달빛 → 핏빛 황혼 → 영혼 안개 → 잿빛 새벽 순으로 바뀝니다.
어느 쪽이 머릿속 그림에 가까운지 골라 주세요. 값은 `Necro Look Volume` 오브젝트의 `Look Preset Cycler`에서 직접 고칠 수도 있습니다.
(이미 장면을 만들어 둔 경우: Tools → Necro → 룩 → 현재 씬에 다크 판타지 분위기 적용을 한 번 누르면 프리셋이 붙습니다)

**배경은 실제 모델입니다.** 묘비 4종, 바위 3종, 죽은 나무 2종, 영혼 등불, 봉인의 제단, 기둥 2종, 납골당, 철 울타리, 무너진 아치 —
`Assets/_Necro/Art/Environment/Graveyard` 에 모델(.fbx)과 텍스처(색 `_albedo`, 굴곡 `_normal`)가 들어 있습니다.
Blender 스크립트로 만들어 렌더로 확인한 것이고, 미리보기 그림은 `docs/images/look_*.png` 에 있습니다.

- 장면을 만들었는데 묘비가 상자 모양이면 모델 파일을 못 받은 것입니다. Git Bash에서 `git lfs pull` 을 실행한 뒤 장면을 "새로 만들기"로 다시 만드세요
- 제단 앞의 **인형 셋과 임시 주인공은 여전히 임시 도형**입니다 (캐릭터 모델은 VRoid·에셋으로 교체 예정)
- 소품의 방향이 뒤집혀 보이거나(납골당 문이 뒤쪽을 향함) 크기가 이상하면 알려 주세요. 가져오기 설정을 맞추면 됩니다

## 2. 스크린샷 보내기

Claude는 Unity 화면을 볼 수 없습니다. 아래 세 장을 보내 주시면 그걸 보고 값을 다듬습니다.

1. 시작 지점에서 제단 쪽을 바라본 전체 모습
2. 제단 앞 인형 셋을 가까이서 (외곽선과 음영이 보이게)
3. 마음에 안 드는 부분이 있으면 그 부분

같이 알려 주시면 좋은 것: 너무 어두운지/밝은지, 보라색이 과한지, 외곽선이 굵은지/가는지, 번지는 빛이 과한지, 떠올리는 게임이나 애니의 장면이 있다면 그 이름.

분홍색(마젠타)으로 보이는 물체가 있으면 셰이더 에러입니다. Console의 빨간 메시지를 그대로 복사해 보내 주세요.

## 3. 주인공 만들기 (VRoid)

1. **VRoid Studio** (무료, 스팀 또는 vroid.com) 설치
2. 주인공 설정: 은보라 긴 머리, 보라색 눈, 검보라 로브, 부서진 금색 왕관 조각. 나이대와 인상은 자유롭게
3. 내보내기: 오른쪽 위 내보내기 → **VRM 내보내기** → **VRM 1.0** 선택
4. Unity에 **UniVRM** 설치: https://github.com/vrm-c/UniVRM/releases 에서 최신 `VRM-...unitypackage` 를 받아 더블클릭 → Import
   - URP용 MToon(애니풍 셰이더)은 VRM 1.0에서만 지원됩니다. 그래서 3번에서 VRM 1.0으로 내보냅니다
5. `.vrm` 파일을 `Assets/_Necro/Art/Characters/Player` 폴더에 끌어다 놓기 (폴더가 없으면 Tools → Necro → 0. 폴더 구조 만들기)
6. 만들어진 모델을 `Look_Graveyard` 장면의 Hierarchy에 끌어다 놓고 **선택한 상태에서** Tools → Necro → **2. 선택한 모델로 플레이어 만들기**
   - 임시 주인공이 지워지고 그 자리에 새 모델이 들어갑니다
7. 걷기·달리기 애니메이션: Mixamo(mixamo.com, 무료)에서 받은 FBX를 `Assets/_Necro/Art/Animations/Player` 에 넣고 Tools → Necro → **3. 플레이어 애니메이터 만들기**
   - 파일 이름에 idle, walk, run, jump, fall 이 들어가면 자동으로 연결됩니다

Unity 6에서 UniVRM이 문제없이 동작하는지는 확인하지 못했습니다. 가져온 모델이 분홍색이거나 에러가 나면 메시지를 보내 주세요.

## 4. 다른 모델에 툰 셰이더 입히기

에셋이나 AI로 만든 모델을 장면에 놓고 선택한 뒤:

- **Tools → Necro → 룩 → 선택한 오브젝트에 툰 셰이더 입히기** — 원래 텍스처와 색을 유지한 채 `Necro/Toon` 셰이더로 바꿉니다. 새 머티리얼은 `Art/Materials/Toon` 에 저장됩니다
- **Tools → Necro → 룩 → 선택한 오브젝트를 지배된 망자로 (영혼 효과)** — 같은 모델에 보랏빛 영혼 불꽃을 입힙니다
- VRoid 모델(MToon)은 이미 애니풍 셰이더라 건드리지 않습니다

머티리얼을 선택하면 Inspector에서 그늘 색, 그늘 경계, 외곽선 굵기, 가장자리 빛, 영혼 효과를 조정할 수 있습니다.

다른 장면에 같은 분위기를 입히려면: Tools → Necro → 룩 → **현재 씬에 다크 판타지 분위기 적용**.

## 알려진 한계

- 배경 소품은 Blender에서는 확인했지만 **Unity로 가져온 모습은 확인하지 못했습니다** (방향, 크기, 노멀맵 적용 여부)
- 셰이더는 Unity 없이 작성해 **한 번도 화면에서 확인하지 못했습니다.** 첫 실행에서 에러나 어색한 부분이 나올 수 있고, 스크린샷을 받아 고칩니다
- 외곽선은 둥근 모델에서 깔끔합니다. 상자처럼 모서리가 각진 모델은 모서리에서 외곽선이 끊어져 보입니다 (각진 배경물에는 툰 셰이더 대신 기본 Lit을 씁니다)
- 투명·반투명 부분이 있는 모델(머리카락 끝, 천)은 툰 셰이더가 아직 지원하지 않습니다
- 뼈대가 있는 모델에도 그대로 쓸 수 있지만, 수십 마리를 한 번에 그리는 최적화는 1장 단계에서 다룹니다
