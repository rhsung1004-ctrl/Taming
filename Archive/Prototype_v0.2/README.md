# 몬스터 테이밍 3D — 프로토타입 v0.2

> v0.2: 실제 3D 모델 연결 기능 추가 — 자세한 방법은 **ASSETS.md**

에셋 없이 코드만으로 돌아가는 첫 프로토타입입니다. 캐릭터·몬스터·섬 지형을 전부 기본 도형으로 자동 생성합니다.
목표는 두 가지 검증입니다: **잡는 맛**(약화 → 먹이 → 교감 미니게임)과 **타는 맛**(펫을 타고 달리고 날기).

## 실행 방법

1. Unity Hub에서 **Unity 6 (6000.x LTS)** 로 새 프로젝트를 만듭니다. 템플릿은 **Universal 3D (URP)**.
2. 이 폴더의 `Scripts` 폴더를 프로젝트의 `Assets` 안에 통째로 복사합니다.
3. 기본으로 열려 있는 `SampleScene`에서 **Play**를 누르면 게임이 자동으로 만들어집니다. (씬에 아무것도 배치할 필요 없음)
4. Game 창 해상도를 **1920x1080** 같은 가로 비율로 맞춰 주세요.

입력 설정(구 Input Manager / 새 Input System)은 어느 쪽이든 자동으로 맞춰 동작합니다.

## 휴대폰(갤럭시)에서 실행

1. File → Build Profiles → **Android** 선택 후 Switch Platform
2. Player Settings
   - Resolution and Presentation → Default Orientation: **Landscape Left**
   - Other Settings → Scripting Backend: **IL2CPP**, Target Architectures: **ARM64** 체크
3. 폰을 USB 디버깅으로 연결 → **Build And Run**

## 들어 있는 것

- **여성 테이머 주인공**: 분홍 포니테일 + 보라 옷 + 지팡이 (도형 조립, 나중에 실제 모델로 교체)
- **테이밍 3단계**: 체력 30% 이하 → 좋아하는 먹이(성공률 +20%) → 바늘 맞추기 미니게임. 실패하면 호감도가 올라 다음 시도가 쉬워짐
- **포획 대기**: 선택한 몬스터가 테이밍 가능해지면 펫들이 알아서 공격을 멈춤 (실수로 죽이는 것 방지)
- **펫 AI**: 따라다니기, 자유/집중/후퇴 지휘, 역할별 스킬(도발·강타·연사·치유), 기절 후 10초 회복, 레벨업
- **속성 상성**: 불>풀>대지>바람>물>불, 1.5배 / 0.7배
- **탈것**: 들늑대(지상), 깃털 새(비행 1단계, 최고 26m), 그리폰(비행 2단계, 최고 75m). 날 때 스태미나 소모
- **섬 맵 (약 480m)**: 남쪽 초원(시작) · 서쪽 숲(늑대) · 동쪽 붉은 언덕(도마뱀) · 북서쪽 큰 산 · 북동쪽 바위 기둥 위 그리폰 둥지(23m) · 남서쪽 하늘 섬(55m)

## 진행 순서 (퀘스트)

1. 젤리 슬라임 테이밍
2. 처음 받은 깃털 새를 타고 북동쪽 바위 기둥 위 그리폰 둥지로 비행 (26m 제한이라 겨우 닿는 높이)
3. 그리폰 테이밍 (좋아하는 먹이: 생고기)
4. 그리폰을 타고 깃털 새로는 못 가던 남서쪽 하늘 섬에 착륙 → 클리어

화면의 금색 ◆ 표시가 다음 목표 위치입니다.

| GameHUD.cs | 멀티터치 조이스틱·버튼·체력바·미니게임·알림 UI |
| WorldBuilder.cs | 섬 지형·바다·나무·바위 기둥·하늘 섬 생성, 몬스터 스포너 |

| Combat.cs | 체력/데미지 공통 처리, 투사체, 보유 펫 데이터 |
| TouchInput.cs | 터치·마우스·키보드 입력 통합 |
